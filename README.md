---

## ✨ Features

- 📝 **Multiple-Choice Questions:** Structured format with instant feedback upon answer selection.
- ⏱️ **Score Tracking & Evaluation:** Calculates score percentage and final grading upon quiz completion.
- 🔄 **Restart & Replay:** Re-attempt quizzes anytime with fresh session state.
- 📱 **Mobile & Desktop Responsive:** Fluid UI that adapts neatly across all screen sizes.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic elements
- **CSS3:** Custom card design, answer status highlighting, and responsive grids
- **JavaScript:** State management, scoring algorithms, and dynamic DOM updates
